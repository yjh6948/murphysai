The iPhone Back-Tap trick

Turn your iPhone into a magic wand: double-tap the back → it does a task for you.
Summarize an article, translate a screen, start focus mode. All free, no coding, about 15 minutes.

This guide assumes you have never opened the Shortcuts app before — every tap is spelled out.

Two things you need to know first

What are "Shortcuts"? A free Apple app already on your iPhone. It chains small actions into a one-tap task. Think Lego: each block is an action (take a screenshot, translate text…), and they run top to bottom.

What is "Back Tap"? A hidden iPhone feature — tapping the back of your phone (double or triple tap) can launch a shortcut. No app icon, no searching.

Will it work on my phone? iPhone 8 and newer, iOS 14+. You do not need the newest iPhone.

30-second crash course

  1. Find the Shortcuts app: swipe down on your Home Screen, type Shortcuts, tap it. (Deleted it? Re-download free from the App Store.)
  2. Make a new one: tap the ＋ in the top-right corner.
  3. Add actions: tap Add Action → a search bar appears → type the action's name → tap it. Repeat to stack more. They run in order, top to bottom.
  4. Variables: a variable is the result of a previous step. When you see a chip like Shortcut Input or Clipboard in a text box, that's a variable. Insert one with the variable button just above the keyboard. This is how a result gets passed into the next step.
  5. Name & save: tap the shortcut name at the top → Rename → type a name → Done.

That's everything. Now let's build the five.

1 — Summarize the screen 🧠

Long article? Double-tap → a clean 3-bullet summary.

Needs the free ChatGPT app installed so its action shows up. No ChatGPT? Skip to #2.

  1. Tap ＋ to start a new shortcut
  2. Add Take Screenshot
  3. Add Extract Text from Image — can't find it? Search text and pick the one that reads text out of a picture. Its input should be the Screenshot from step 2
  4. Add Ask ChatGPT. In its text box type Summarize this in 3 short bullets in English: then insert the Extracted Text variable right after it
  5. Add Make Rich Text from Markdown (input = the ChatGPT answer). This makes the result look clean instead of messy
  6. Add Quick Look
  7. Rename it Summarize

Test it: open any article, then tap ▶ at the bottom of the shortcut. A tidy summary should pop up.

2 — Translate the screen 🌐

See another language? Double-tap → read it in yours. Fully built-in, no app needed.

  1. New shortcut (＋) → add Take Screenshot
  2. Add Extract Text from Image (input = Screenshot)
  3. Add Translate Text → set the "to" language to yours (input = Extracted Text)
  4. Add Show Result
  5. Rename it Translate

3 — Deep Work mode 🎯

One tap = distraction-free work session.

  1. New shortcut → add Set Focus → choose Do Not Disturb → Turn On
  2. Add Set Low Power Mode → On
  3. Add Start Timer → 25 minutes
  4. (Optional) Add Play → pick a focus playlist
  5. Rename it Deep Work

4 — Get me home 🏠

Leaving somewhere? Double-tap → texts your ETA and opens directions.

  1. New shortcut → add Get Travel Time → destination Home, by car
  2. Add Send Message → type Heading home, ~ then insert the Travel Time variable, then out → choose who to text
  3. Add Show Directions → Home
  4. Rename it Get Me Home

First run may ask for location permission — allow it.

5 — Capture an idea 💡

Idea hits? Double-tap, say it out loud, it's saved.

  1. New shortcut → add Dictate Text (this listens to your voice)
  2. Add Append to Note → pick or create a note called Ideas
  3. Rename it Capture Idea

Now put them on your Back Tap

Back Tap has two slots: Double Tap and Triple Tap. Pick your two favorites to launch by tapping the back. Run the other three anytime from inside the Shortcuts app.

  1. Open Settings
  2. Go to Accessibility → Touch → Back Tap
  3. Tap Double Tap → choose a shortcut (e.g. Summarize)
  4. Tap Triple Tap → choose another (e.g. Translate)

Done. Tap the back of your phone twice and your shortcut runs. 🖤

If something isn't working

An action isn't in the list

Names change a bit by iOS version — search a keyword (text, translate, focus, timer).

"Ask ChatGPT" is missing

Install the free ChatGPT app first, then reopen Shortcuts.

Result shows as code or looks messy

Make sure step 5 is Make Rich Text from Markdown, placed before Quick Look.

Nothing happens on back tap

Recheck Settings → Accessibility → Touch → Back Tap is set to your shortcut.
